# CodeLens 经典算法与数据结构可视化

CodeLens 提供 77 个可交互的教学主题。你可以修改示例输入，逐步观察算法怎样改变数组、树、图或动态规划表，并对照当前执行的代码行。

## 本地打开

在仓库页面选择 **Code → Download ZIP**，完整解压后，用 Edge 或 Chrome 打开根目录的 `index.html`。页面使用本地资源，可离线运行。

## 试用一个例子

1. 搜索“冒泡排序”，保留默认数组或输入自己的整数序列。
2. 点击“生成步骤”，再点“下一步”，对照图示和代码观察一次比较或交换。
3. 点击“播放”连续观察，或调低速度阅读步骤说明。经典代码支持语言切换和全屏阅读。

## 目录

- `index.html` 是站点入口。
- `assets/scripts/` 包含算法教学数据、步骤生成、可视化与播放交互脚本。
- `assets/styles/` 包含布局、主题和图示样式。
- `.nojekyll` 用于 GitHub Pages 静态发布。
