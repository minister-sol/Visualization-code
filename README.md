# C 执行可视化 · 初始版本

输入一段 C 代码，观察源码行、变量、数组、函数调用栈和输出如何随执行变化。项目优先打通自定义代码到执行记录、再到动画回放的流程，并为冒泡排序、选择排序等教学场景提供示例。

## 启动

需要 Python 3.12 或更新版本。在项目目录运行：

```powershell
python server.py
```

浏览器打开 http://127.0.0.1:8000 。如端口被占用，可用 `python server.py --port 8001`。停止服务按 Ctrl+C。Windows 也可运行 `./start.ps1`。

项目随附 pycparser 及其许可，可离线运行后端，不需要 GCC、Node 或额外构建前端。更新解析器时可通过 `python -m pip install -r requirements.txt --target backend/vendor` 安装，随后重新检查第三方许可。

## 使用

选择示例或编辑代码，运行后通过播放、单步、回退和时间轴检查状态。数组视图中的下标和值对应当前步骤的快照；终端区域展示截至当前步骤产生的输出。修改代码后需要重新运行。

## 架构

`web/` 是浏览器界面；`server.py` 提供静态文件和 JSON API；`backend/engine.py` 使用 pycparser 解析语法树，并由受限教育解释器生成执行快照；`backend/examples.py` 提供示例。回放操作读取已有快照，不会重复执行用户程序。

- `GET /api/examples`：返回示例列表。
- `POST /api/trace`：接收 `{"code":"int main(){return 0;}","stdin":""}`，返回步骤或错误。

服务默认仅监听本机地址，设置了源码长度和执行步数限制。该版本适合本机学习体验；公开部署前需要进一步的资源隔离和服务治理。

## 能力边界

初版采用教育解释器，不是完整 C 编译器。支持的基础语法、数组、函数等能力以示例与测试为准；整数宽度、溢出、内存布局等行为不能等同于真实平台。暂不应依赖本版本验证生产 C 程序的正确性。

现已支持 int/void 声明、int 一维数组、for/while/do while、if、函数与递归、printf（%d、%i、%%）/puts、短路逻辑与位运算。数组动画最多展示前 60 项。浮点、char 变量等尚未支持；整数超出支持范围会报错。

指针、动态内存、结构体、switch、多维数组、文件、宏、多文件及完整标准库等属于后续扩展范围；不支持的代码应明确报错。标准输入框为后续功能预留，目前不支持 scanf。完整知识体系与验收路线见 [docs/COVERAGE.md](docs/COVERAGE.md)。

## 验证

```powershell
python -m unittest discover -s tests -v
```

覆盖示例执行、递归、越界、死循环限制、不支持语法，以及真实 HTTP 请求下的页面、示例、执行和错误恢复。当前 7 项测试通过。

## 后续方向

完善 C 语义和错误定位，增加指针/结构体/链表动画，接入隔离的真实编译器和调试器，再通过统一执行事件协议扩展 Python、C++ 和 Java。
