# CodeLens · 通用 C 代码执行可视化

输入新的 C 源码，解析为语法树并在受限解释器中执行，生成逐步状态，再由通用界面展示。执行器不读取示例 ID，不按算法或字段名称选择动画。

## 启动与使用

需要 Python 3.12 或更新版本：

```powershell
python server.py
```

打开 http://127.0.0.1:8000 。端口占用时用 `python server.py --port 8001`。随附 pycparser，运行不依赖 GCC、Node 或联网。编辑源码并提供标准输入后运行，可播放、表达式单步、按源码行前进、跳出调用、点击行号设置回放断点、继续到下一断点、跟踪数据路径的下一次变化、回退、拖动时间轴、筛选执行事件和搜索表达式。

运行错误会显示源码行并保留此前轨迹，允许回放错误现场。解析错误没有执行记录。

## 从状态生成视图

- 源码行、表达式结果、读写事件、输入进度和输出随每步更新。
- 矩形二维数组自动生成矩阵网格，可切换为逐行视图；每个区域显示最多30行和30列，可切换区域并自动定位当前访问。
- 数组按实际身份与偏移定位；原数组、函数参数和指针别名可以同步高亮对应元素。每段显示最多60项，可换段并自动定位当前访问。
- 字符数组显示字符及数值，并区分空格、换行和零终止符。
- 结构体和动态节点形成对象图，任意字段名、共享引用、环和多条出边均由真实引用生成。图按引用关系分层，支持缩放、全图适配、定位、对象详情和有效对象筛选；大量空指针可折叠或展开。
- 调用栈可展开查看每一层的参数和局部作用域，同名遮蔽变量分开呈现。

## 当前可运行范围

| 领域 | 支持内容 |
|---|---|
| 基础 | 整数、有限 float/double、char、_Bool、void；表达式、条件、循环、switch/case/default、函数和递归 |
| 数组 | 一维、多维、变长、结构体及指针数组；嵌套花括号与受限指定初始化 |
| 复合数据 | 具名结构体，整数、字符、数组、结构体和指针成员；按值复制、参数与返回 |
| 引用 | &、*、.、->、指针参数/返回、数组退化、下标、同数组内算术/差/比较、尾后指针 |
| 类型声明 | 文件级 typedef、文件及块作用域 enum、整数枚举表达式 |
| 动态内存 | 带类型描述的 malloc/calloc/realloc/free；整数、字符、指针数组及结构体节点池；数组扩缩容 |
| 字符串 | ASCII 字符/字符串初始化、字面量字符指针、strlen、strcmp、strcpy、strcat、puts、printf %s/%c |
| 输入输出 | printf %d/%i/%lld/%lli/%%；scanf 整数/%f/%lf/%c/%s/%Ns；有限浮点 %f/%e/%g 输出，输入运行前一次性提供 |
| 预处理 | 单行对象式 #define、#undef；stdio.h、stdlib.h、string.h 内置环境 |

指定初始化支持显式字段/下标嵌套路径（如 .data[2]、[1].key），复合值也可使用嵌套花括号；支持跨子数组和成员的普通续填；支持常见重复与局部覆盖，完整初始化约束检查仍有限制。枚举定义支持文件与块作用域；局部 typedef 支持已有类型、定长及变长数组别名。

## 模型限制

这是教学解释器，不是完整 C 编译器。对象 ID 和引用不是原生机器地址。sizeof 返回解释器布局模型的字节数，并在直接分配表达式中保留元素类型；模型使用1字节char/布尔、2字节short、4字节int、4字节float、8字节double/long long/指针和自然对齐，不保证所有平台ABI一致。

- int 为32位、long long 为64位、char 为有符号8位；超范围赋值拒绝，不模拟全部平台转换与溢出行为。
- 分配采用元素类型和数量；realloc 支持整数、字符、指针和结构体数组并始终移动；保留原有成员值，新增元素未初始化，旧引用失效；零长度 realloc 暂不支持。
- 尚不支持完整浮点环境（NaN/Inf、long double及浮点异常等）、完整类型兼容/存储期、完整字符串库、完整函数指针类型语义、通用字节内存、完整预处理、多文件或多语言输入。
- 位域（包括匿名和零宽位域）、union、goto 和不带类型描述的裸字节分配会明确拒绝。
- 完整初始化类型检查、复杂枚举和初始化组合等写法仍有限制。字符串字面量只读。
- 复杂图仍可能有交叉线；临时返回值对象保留在对象图中，完整临时对象生命周期待完善。

服务只监听本机。限制包括源码50KB、标准输入100KB、30000次操作、3000个普通步骤、轨迹16MB、单数组最多1000元素、最多200次动态分配、递归深度80。错误现场与完成帧可作为附加帧出现。

## 验证与覆盖证据

```powershell
python scripts/check.py          # Python 单元/HTTP + 两项 Node 测试
python scripts/check.py --gcc    # 加跑 GCC 输出和退出码对照
```

检查使用 Python 3.12 和 Node.js（CI 使用 Node 24）；pycparser 随仓库提供，无需额外安装 Python 第三方包或 npm 包。`--gcc` 需要 PATH 中有 GCC，不提供此参数时会明确显示跳过 GCC。HTTP 测试需要允许本机回环网络连接；失败会使检查返回非零状态。GitHub Actions 在推送和 PR 时执行包含 GCC 的检查；浏览器回归不包含在该检查中，前置条件与覆盖缺口见 [docs/COVERAGE.md](docs/COVERAGE.md)。

2026-11-11 的一次独立验证运行了 536 项 Python 测试，其中 5 项 HTTP 测试因沙箱禁止本机连接而报错，其余通过；两项 Node 测试通过，103 段程序的输出和退出码与 GCC 一致。测试数量随代码变化，以实际运行结果为准。覆盖包括顺序表、链表、栈、循环队列、堆、哈希、并查集、二叉搜索树、Trie、线段树、矩阵 BFS 和节点池 DFS。

浏览器已验证链表、节点池图、Trie展开/折叠、字符视图、偏移别名高亮、递归调用帧、错误回放和执行事件导航。检查脚本与截图位于本地 artifacts/，该目录不纳入版本控制。输出对照与有限语料不能证明任意 C 源码或全部中间语义正确。

完整目标仍在推进，当前不能宣称覆盖绝大多数任意代码写法。证据与未完成事项见 [docs/COVERAGE.md](docs/COVERAGE.md)。

## 架构与接口

backend/engine.py 负责执行与快照，backend/preprocess.py 负责受限宏展开，web/object-layout.js 根据引用布局，web/app.js 回放快照，server.py 提供本机服务。

- GET /api/examples：可编辑示例。
- POST /api/trace：`{"code":"int main(){return 0;}","stdin":""}`。
- 成功返回 steps/output/status；失败使用HTTP400，并返回 error/line，运行时错误还包含 steps/output。

字符串输入：%s/%Ns 逐字符写入并记录输入进度，容量不足会报错而非越界；%c 保留输入空白，格式中的空白可主动跳过空白。当前字符输入限定 ASCII。

字符串写入：strcpy/strcat 逐字符生成写入事件，保留字符数组身份，检查终止符空间、重叠区域与只读字面量；返回目标引用。

回放差异依据数组身份和元素位置比较，支持成员路径和跨函数别名；浏览器已验证成员数组单次读取时其余元素不误标更新，并重新通过偏移别名高亮检查。

状态差异视图：与前一帧对照变量、嵌套数组、节点字段及释放状态，最多显示24处变化。函数切换不把当前可见局部变量的切换视为修改；同一结构体也可能同时以变量路径和对象ID显示。浏览器已验证 q.values[1] 从4变为9及回放，截图 artifacts/diff-preview.png。

显式整数转换：支持 (int)/(long long)/(char) 和已支持的枚举类型，转换生成 compute 事件。模型对缩窄转换保留低位并按补码解释；这是明确的模型选择，不保证所有 C 平台的实现定义转换行为。非零整数地址转换仍拒绝。

局部类型别名：按词法作用域解析整数、指针、已有结构体、定长及变长数组别名，退出内层恢复外层定义。变长数组别名在typedef执行时捕获维度，之后修改原长度变量不会改变已有类型。

函数原型：支持先声明后定义、void参数表、数组参数退化匹配及相互递归，检查已支持类型的声明/定义冲突和重复定义。完整 C 函数类型兼容规则、可变参数用户函数仍未实现。

const 更新：支持只读标量/数组、const 指针变量、只读指针参数和结构体视图；实际只读对象通过别名写入也会报错。volatile/restrict、复杂限定符兼容与强制去除 const 的全部 C 规则未实现；当前模型保留只读视图的保护。

源码导航只读取已有快照，不重复执行代码。下一源码行跳过更深调用，跳出调用停在调用者状态；错误与完成帧始终保留。单行排版代码可能直接跳到结束，表达式单步仍可查看细节。浏览器已验证递归从第5层跳到第4层，以及越过内部递归返回 main 第6行。

下标定位：数组事件记录下标表达式、求值时读取的变量/元素、逻辑下标与实际元素位置。界面可解释嵌套索引及偏移别名，不依据变量名猜测算法。浏览器已验证 alias[0] 的逻辑下标0、存储位置1和双视图高亮。

矩阵视图浏览器验证：2×3矩阵显示6个单元格，赋值仅高亮 cost[1][2]=9，逐行切换显示2行，回放操作正常。截图 artifacts/matrix-preview.png。

内置头文件常量：stdio.h/stdlib.h/string.h 环境提供 NULL，stdio.h 另提供 EOF；支持后续 #undef。头文件只提供已实现的能力，不代表完整标准库。

端到端验收：12类数据结构源码直接填入编辑器运行，输出与预期一致，自动生成对象/数组/矩阵视图，往返跳转不改变执行记录。报告 artifacts/acceptance-report.json。验收修正了完成帧布尔状态0/false差异造成的假指针变化，新增类型稳定性回归检查。

布尔更新：支持 _Bool 以及 stdbool.h 的 bool/true/false，赋值和转换规范化为0/1，运算进行整数提升。快照提供布尔类型路径，视图以 true/false 和数值显示，普通整数0/1保持整数视图。布尔视图已通过浏览器检查。

对象节点宽度按实际字段和值调整（205–420像素），超长内容省略并通过悬停标题保留全文。浏览器已验证长字段名、64位精确值、两节点引用和 true/false 数组展示，截图 artifacts/typed-preview.png。

无符号整数：支持 unsigned int、unsigned long long、unsigned char、u/ULL常量和 %u/%llu 输出；赋值与相应运算按位宽回绕，较小整数提升，函数返回按声明转换。scanf 无符号格式及全部 C 整数类型组合仍未实现。161项测试通过，含哈希混合程序的 GCC 对照。

固定宽度类型：stdint.h 内置环境提供 int8_t/uint8_t 至 int64_t/uint64_t 以及相应 MIN/MAX 常量；short/unsigned short 使用16位模型。头文件展开保留源码行号，不读取系统头文件。165项测试通过，新增固定宽度位图 GCC 对照。

无符号输入：scanf 支持 %u/%llu/%hu/%hhu 和 %hd/%hhd，检查位宽及符号类型，允许合法指针变量作为目标；输入转换后以实际存储值生成写入事件。模型拒绝超出支持范围的输入，避免宣称覆盖全部原生 scanf 边界行为。

局部结构体更新：支持块内内联 typedef、结构体标签遮蔽和局部前置标签；不同匿名结构体保持不同类型身份。表达式显示原始标签名，内部作用域编号不进入用户视图。

sizeof 更新：支持数组长度比值、结构体填充、指针/字符串大小、已有变长数组及其子数组尺寸，i++ 等非变长操作数不执行。stddef.h 和常见内置头文件提供模型 size_t，支持 %zu 输出。仍不支持任意裸字节 malloc，任意数值运算后的分配类型追踪仍有限制。

分配大小变量：sizeof 来源的类型信息可经不改变数值的整数赋值、参数/返回和数组存储保留，因此支持 size_t bytes=n*sizeof(*p); malloc(bytes)。快照仍输出普通数字。复杂算术、显式转换后类型追踪及任意裸字节 malloc 仍有限制。

分支求值说明：&&/|| 记录右侧是否执行，三元表达式记录选择及跳过的分支；界面显示实际分支决策，不执行被跳过的表达式。浏览器已验证空指针保护和跳过自增，截图 artifacts/decision-preview.png。

表达式类型更新：三元表达式在不执行未选分支的前提下应用共同整数类型，支持已实现的相容指针/零、结构体和void分支；sizeof 可查询普通算术、赋值和逗号表达式类型。复杂指针限定符和全部 C 条件表达式兼容规则仍有限制。

花括号省略初始化：支持多维数组 {0}、连续值、混合显式行、结构体数组、二维字符行和外层长度推导，标量 {value} 也可使用。初始化表达式只执行一次；复杂指定路径与省略花括号混用仍有限制。

内存库子集：memset/memcpy/memmove 支持模型可定位的完整标量、数组和结构体单元，考虑模型结构体填充，产生逐单元读写事件。memmove 先保存源数据以处理重叠；memcpy 重叠会报错。部分字节截断、不同单元布局重解释和未初始化单元复制暂不支持，指针填充仅允许零，布尔填充仅允许0/1。浏览器已验证矩阵清零的单元高亮与回放。

静态存储更新：局部 static 初始化一次并跨调用保留，支持标量、数组、结构体及返回其地址；全局 static 和单文件 static 函数可用。静态环形哨兵和普通结构体的自地址初始化已覆盖。完整静态初始化常量约束、跨文件链接及复杂子对象自引用仍有限制。

局部枚举更新：枚举常量按当前词法作用域绑定并保持只读，块退出后不泄漏，普通变量遮蔽枚举名时使用实际声明类型。局部枚举 typedef、重复函数调用和模型 sizeof(enum) 已覆盖。

整数库函数：支持 abs、labs、llabs，按 int32 / long64 / long long64 模型转换参数并返回；有符号最小值的绝对值溢出会保留错误轨迹。

字符串查找：支持 strchr、strrchr、strstr，返回保留原数组身份与偏移的字符指针；未匹配返回空引用。

定长字符串操作：支持 strncmp 按需比较与 strncpy 截断/补零。strncpy 达到长度限制时不会自动添加终止符，字符读写逐步进入轨迹。

断言：支持 assert.h 的 assert，检查只求值一次；失败保留条件结果、源码行及错误前轨迹。NDEBUG 在包含头文件时禁用断言，重新包含可更新状态。

条件展示区分普通分支、比较表达式、短路逻辑、三元选择和断言；可选浏览器回归：`node tests/browser_conditions.mjs`（使用 VISUALIZER_URL 与 CDP_URL 指定已运行的服务）。

内存比较：支持 memcmp 的逐字节读取与首个差异比较，读取关联原数组/字段。模型采用小端整数与float32/double64字节表示，不支持比较指针表示和结构体填充字节。非ASCII可打印字节在字符视图中显示为十六进制转义及十进制数值。

程序退出：支持 exit、EXIT_SUCCESS、EXIT_FAILURE，保留提前结束前的执行轨迹。结果包含 exit_code 与 termination；main返回值也记录为退出码。可选浏览器检查：`node tests/browser_exit.mjs`。

外部声明：支持同一输入中的 extern 函数/对象声明、局部 extern 全局绑定，以及未指定外层长度的数组声明。检查对象类型冲突；不提供多文件链接或外部库符号加载。

全局对象暂定定义会合并为一次分配与初始化，重复无初始化声明不会清零已有对象。支持数组长度补全、剩余未知外层长度暂定数组按一个元素处理，并拒绝重复初始化定义。

聚合自引用初始化：先建立数组/结构体存储，再填入初值，支持节点池初始化引用后续节点及其成员地址；静态局部节点池保留跨调用身份。

随机化算法：支持rand/srand与RAND_MAX=32767，使用固定模型伪随机序列以便复现，不保证与本机C库序列一致。
