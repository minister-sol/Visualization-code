## 3. 分组结论（页面可直接采用）

**C 组（I/O 与转换）**

1. 三个返回值要分开讲：`printf`/`fprintf`/`snprintf` 返回**字符数**；`scanf`/`fscanf` 返回**赋值项数**，`0` 是匹配失败、`EOF` 是首个转换前就失败；`fread`/`fwrite` 返回**元素个数**。
2. `snprintf` 截断时返回值仍是“若无限制本该写入的长度”，`>= n` 就说明被截断；`n=0` 时缓冲区可为 `NULL`。
3. `fgets` 的 `n` 是缓冲区大小（含 NUL），最多读 `n-1` 字节，换行**保留**。
4. `atoi` 没有错误检测，超范围是 UB；可判定的错误必须用 `strtol`/`strtod` 的 `endptr` 与 `errno`。

**D 组（动态内存与排序查找）**

1. `realloc` 失败返回 `NULL` 且**旧块仍有效**；绝不能 `p = realloc(p, n)` 直接覆盖。
2. `calloc` 初始化为“全零位”，但全零位不等于所有类型的零值（指针/浮点尤其不能当保证）。
3. `qsort` 不保证稳定；比较器必须给出全序且不得改数组。
4. `bsearch` 的前提是**已按同一比较器排好序**；重复元素返回哪一个未指定（本机命中偏移 5）。

**E 组（文件）**

1. `fopen` 失败返回 `NULL`，"w" 会截断已有文件；文本/二进制模式在 Windows 上有换行转换差异。
2. `fclose` 成功 0、失败 `EOF`，并负责刷新缓冲；关闭后流不可再用。
3. `fread` 短计数（要 5 得 3）就是 EOF/错误的信号，不能用 `feof` 之外的猜测代替。
4. 文本模式下 `fseek` 只保证 `ftell` 返回值可回跳；按字节偏移定位请用二进制模式。

**F 组（数学、随机、时间）**

1. 数学函数的错误是“域错误/极点错误/范围错误”，`sqrt(-1)` 得 NaN、`strtod` 溢出得 `HUGE_VAL` 并置 `ERANGE`，页面要演示这些而不是崩溃。
2. `floor`/`ceil`/`round` 返回 `double`；`ceil(-0.5)`、`round(-0.4)` 得 `-0.0`，`signbit` 可见。
3. `rand` 只保证 `[0, RAND_MAX]` 和“同种子同序列”，具体数值是实现定义（本机 `srand(1)` 首值 41）。
4. `clock` 是**处理器时间**，`CLOCKS_PER_SEC` 因实现而异（本机 1000，POSIX 常见 1000000），秒数必须除以它。

## 4. 逐函数记录

### 4.1 C 组：输入输出与转换（10 项）

#### 38. `printf` — §7.21.6.3
- **头文件 / 原型 / 条款**：`#include <stdio.h>`；`int printf(const char * restrict format, ...);`；§7.21.6.3
- **参数与单位**：`format` 中的转换说明必须与后续实参类型一一匹配；返回值单位是**字符数**
- **调用前提**：`format` 非空；`%s` 实参以 NUL 结尾；`%p` 只接受 `void *`
- **返回值**：实际传输的字符数；输出错误时为负值（负值大小实现相关）
- **影响**：写入 `stdout`，不改任何实参
- **提醒**：`%d` 传 `long`、`%f` 传 `int` 都是 UB；`printf` 的返回值可用于检查是否全部写出
- **三例**：默认 `printf("abc")` → 返回 `3`；自定义 `printf("%d|%s\n", 42, "x")` → `5`（"42\|x\n"）；边界 `printf("%5.2f\n", 3.14159)` → `6`（" 3.14" 5 字符 + 换行）
- **实测**：PASS（3 项，控制台可见 `abc`、`42|x`、` 3.14`）

#### 39. `scanf` — §7.21.6.4
- **头文件 / 原型 / 条款**：`<stdio.h>`；`int scanf(const char * restrict format, ...);`；§7.21.6.4
- **参数与单位**：转换说明 + 目标对象指针；`%d`→`int *`，`%c`→`char *`，`%s`→`char` 数组；数值按十进制等格式解析
- **调用前提**：指针类型与转换说明匹配；`%s`/`%[` 建议带宽度；流处于可读状态
- **返回值**：成功赋值的项数；首个转换前遇输入失败返回 `EOF`；匹配失败返回 `0`（已赋值 0 项）
- **影响**：写入目标对象；`%s` 不配宽度会按输入长度写越界
- **提醒**：多数转换自动跳过前导空白，`%c`、`%[`、`%n` 不跳；区分 `0` 与 `EOF` 是判断输入结束的关键
- **三例**：默认 输入 `42 hello` → `scanf("%d")` 返回 `1`、得 `42`；自定义 输入 `abc` → 返回 `0` 且变量不变；边界 无输入（EOF）→ 返回 `EOF`
- **实测**：PASS（io_stdin 4 项 + scanf_fail 4 项）

#### 40. `getchar` — §7.21.7.6
- **头文件 / 原型 / 条款**：`<stdio.h>`；`int getchar(void);`（等价 `getc(stdin)`）；§7.21.7.6
- **参数与单位**：无参数；每次读 **1 字节**
- **调用前提**：`stdin` 可读
- **返回值**：下一个字符，作为 `unsigned char` 转 `int`；文件结束或读错误返回 `EOF`
- **影响**：推进 `stdin` 位置，消耗该字节
- **提醒**：必须用 `int` 接收，用 `char` 接会把 `0xFF` 与 `EOF` 混淆
- **三例**：默认 输入 `w` → 返回 `'w'`；自定义 `scanf("%s")` 后留下的空格 → 返回 `' '`；边界 输入耗尽 → `EOF`
- **实测**：PASS（io_stdin 3 项）

#### 41. `putchar` — §7.21.7.8
- **头文件 / 原型 / 条款**：`<stdio.h>`；`int putchar(int c);`（等价 `putc(c, stdout)`）；§7.21.7.8
- **参数与单位**：`c` 为 `int`，写出其 `unsigned char` 值；单位 1 字节
- **调用前提**：`stdout` 可写
- **返回值**：写入的字符（`int`）；出错返回 `EOF`
- **影响**：向 `stdout` 追加 1 字节
- **提醒**：返回值不是“成功/失败”布尔，而是字符本身，和 `EOF` 比较才算错误判断
- **三例**：默认 `putchar('X')` → 返回 `88` 并输出 `X`；自定义 `putchar('7')` → `55`；边界 `putchar('\n')` → `10`
- **实测**：PASS（3 项）

#### 42. `puts` — §7.21.7.9
- **头文件 / 原型 / 条款**：`<stdio.h>`；`int puts(const char *s);`；§7.21.7.9
- **参数与单位**：`s` 为以 NUL 结尾的字符串；自动追加 1 个换行
- **调用前提**：`s` 非空指针且已终止
- **返回值**：成功返回非负值；写错误返回 `EOF`
- **影响**：将 `s` 与换行写入 `stdout`，不改 `s`
- **提醒**：`puts` 自带换行，别再手动加 `"\n"`；空串会输出一个空行
- **三例**：默认 `puts("hi")` → 输出 `hi\n`、返回非负；自定义 `puts("")` → 只输出一个换行、返回非负；边界 打印含 `'\n'` 的串会得到两个换行（按标准）
- **实测**：PASS（2 项，输出 `hi` 与空行）

#### 43. `fgets` — §7.21.7.2
- **头文件 / 原型 / 条款**：`<stdio.h>`；`char *fgets(char * restrict s, int n, FILE * restrict stream);`；§7.21.7.2
- **参数与单位**：`n` 是**缓冲区大小**（含终止符），最多读 `n-1` 字节
- **调用前提**：`s` 至少 `n` 字节可写；`stream` 可读；`n ≥ 1`
- **返回值**：成功返回 `s`；文件结束且未读到字符、或读错误时返回 `NULL`
- **影响**：写入 `s`，总是补 `'\0'`；换行若放得下会被保留
- **提醒**：`n` 不是“要读多少字符”；`NULL` 不区分 EOF 与错误，需要 `feof`/`ferror` 才能分开
- **三例**：默认 行 `line1\n`、`n=32` → `"line1\n"`；自定义 `n=8` 读剩余 `"orld\n"` → `"orld\n"`（5 字节，含换行）；边界 无输入 → `NULL`
- **实测**：PASS（io_stdin 5 项，含 `"orld\n"` 续读与 EOF）

#### 44. `snprintf` — §7.21.6.5
- **头文件 / 原型 / 条款**：`<stdio.h>`；`int snprintf(char * restrict s, size_t n, const char * restrict format, ...);`；§7.21.6.5
- **参数与单位**：`n` 是缓冲区容量（字节，含 NUL）；返回值单位是字符数（不含 NUL）
- **调用前提**：`n > 0` 时 `s` 至少 `n` 字节；`n = 0` 时 `s` 可为 `NULL`
- **返回值**：若无 `n` 限制本应写入的字符数；截断不影响该值；编码错误返回负值
- **影响**：写入至多 `n-1` 个字符并补 NUL（`n=0` 时什么都不写）
- **提醒**：返回值 `>= n` 就表示被截断，这是唯一可靠的截断信号；`n` 必须 ≥1 才有终止符
- **三例**：默认 `snprintf(b, 6, "%s", "hello")` → 返回 `5`、得到 `"hello"`；自定义 `n=4` → 返回 `5`、得到 `"hel"`；边界 `snprintf(NULL, 0, "%s", "hello")` → `5`
- **实测**：PASS（6 项）

#### 45. `atoi` — §7.22.1.2
- **头文件 / 原型 / 条款**：`<stdlib.h>`；`int atoi(const char *nptr);`（等价于 `(int)strtol(nptr, NULL, 10)`）；§7.22.1.2
- **参数与单位**：以 NUL 结尾的字符串；解析十进制整数
- **调用前提**：`nptr` 有效
- **返回值**：可表示时返回对应的 `int`；无数字返回 `0`
- **影响**：无
- **提醒**：没有错误检测，结果超出 `int` 是 UB；转换失败与“真的读到 0”无法区分，工程代码用 `strtol`
- **三例**：默认 `atoi("42")` → `42`；自定义 `atoi("  -17xyz")` → `-17`；边界 `atoi("abc")` → `0`，`atoi("")` → `0`
- **实测**：PASS（5 项）

#### 46. `strtol` — §7.22.1.4
- **头文件 / 原型 / 条款**：`<stdlib.h>`；`long int strtol(const char * restrict nptr, char * restrict * restrict endptr, int base);`；§7.22.1.4
- **参数与单位**：`base` 为 `0` 或 `2`–`36`；`base 0` 按前缀判断（`0x` 十六进制、`0` 八进制）；`endptr` 可为 `NULL`
- **调用前提**：`nptr` 有效；`base` 合法；判断范围错误前先把 `errno` 清零
- **返回值**：转换结果；无可转换字符返回 `0` 且 `*endptr == nptr`；上/下溢返回 `LONG_MAX`/`LONG_MIN` 并置 `errno = ERANGE`
- **影响**：写 `*endptr`（若不为 `NULL`）
- **提醒**：`endptr` 是判断“整串是否都转完”的唯一手段；`base 0` 下 `"077"` 是八进制 `63`，容易被误读
- **三例**：默认 `strtol("42", &e, 10)` → `42`、`*e=='\0'`；自定义 `strtol("0x1F", &e, 0)` → `31`；边界 `strtol("abc", &e, 10)` → `0`、`*e=='a'`；溢出串 → `LONG_MAX` + `ERANGE`
- **实测**：PASS（9 项）

#### 47. `strtod` — §7.22.1.3
- **头文件 / 原型 / 条款**：`<stdlib.h>`；`double strtod(const char * restrict nptr, char * restrict * restrict endptr);`；§7.22.1.3
- **参数与单位**：接受十进制、指数、十六进制浮点（`0x1p3`）、`inf`、`nan`
- **调用前提**：`nptr` 有效；查 `ERANGE` 前先清零 `errno`
- **返回值**：最接近的 `double`；无转换返回 `0.0` 且 `*endptr == nptr`；上溢返回 `±HUGE_VAL` 并置 `ERANGE`；下溢返回不超过最小正规数的值（可能置 `ERANGE`）
- **影响**：写 `*endptr`
- **提醒**：`"0x1p3"` 是 8.0 不是 0；`nan`/`inf` 能被解析，输入校验不能只看 `strtod` 成功
- **三例**：默认 `strtod("3.5", &e)` → `3.5`；自定义 `strtod("1e3", &e)` → `1000.0`；边界 `strtod("1e400", &e)` → `+inf` 且 `errno==ERANGE`，`strtod("abc", &e)` → `0.0`
- **实测**：PASS（7 项，含 `0x1p3`→8、`-inf`、`nan`）

### 4.2 D 组：动态内存与排序查找（6 项）

#### 48. `malloc` — §7.22.3.4
- **头文件 / 原型 / 条款**：`<stdlib.h>`；`void *malloc(size_t size);`；§7.22.3.4
- **参数与单位**：`size` 为**字节数**
- **调用前提**：`size` 可为 0（实现定义）
- **返回值**：成功返回适合任何基本对齐的空块首地址；失败返回 `NULL`
- **影响**：分配一块未初始化存储；需 `free` 归还
- **提醒**：内容未初始化；`malloc(0)` 可能返回 `NULL` 也可能返回可 `free` 的指针；`sizeof` 用对象写法避免类型写错
- **三例**：默认 `malloc(10 * sizeof(int))` → 非空且 10 个元素可读写；自定义 二次分配用于 `realloc`；边界 `malloc(0)` → 实现定义（本机返回非空指针）
- **实测**：PASS（3 项 + 1 条 INFO）

#### 49. `calloc` — §7.22.3.2
- **头文件 / 原型 / 条款**：`<stdlib.h>`；`void *calloc(size_t nmemb, size_t size);`；§7.22.3.2
- **参数与单位**：`nmemb` 元素个数、`size` 每元素字节；总量为乘积
- **调用前提**：乘积应可表示；实现不保证检测乘法溢出
- **返回值**：成功返回全零位初始化的块；失败返回 `NULL`
- **影响**：分配并清零
- **提醒**：全零位不保证等于“所有类型的零值”（指针、浮点尤其如此）；溢出检测不要依赖 `calloc`
- **三例**：默认 8 个元素在 `calloc(8, sizeof(int))` 后全为 0；自定义 `calloc(1, sizeof(int))` 单元素为 0（按标准）；边界 `calloc(0, n)` 为 0 字节请求，返回值为实现定义或 `NULL`（按标准，不演示）
- **实测**：PASS（2 项）

#### 50. `realloc` — §7.22.3.5
- **头文件 / 原型 / 条款**：`<stdlib.h>`；`void *realloc(void *ptr, size_t size);`；§7.22.3.5
- **参数与单位**：`size` 为新块字节数；`ptr` 为 `NULL` 时等价 `malloc`
- **调用前提**：`ptr` 必须是 `malloc`/`calloc`/`realloc` 返回且未释放的指针
- **返回值**：成功返回新块（地址可与旧块相同）；失败返回 `NULL`，**旧块不被释放且内容有效**
- **影响**：可能搬移并释放旧块；保留 `min(旧大小, 新大小)` 字节
- **提醒**：写 `p = realloc(p, n)` 会在失败时丢掉旧指针；必须用临时变量接
- **三例**：默认 4→8 个 `int` 扩容 → 前 4 个值保留；自定义 8→2 缩容 → 前 2 个保留；边界 请求 `2^62` 字节 → `NULL` 且旧块仍可读
- **实测**：PASS（6 项）

#### 51. `free` — §7.22.3.3
- **头文件 / 原型 / 条款**：`<stdlib.h>`；`void free(void *ptr);`；§7.22.3.3
- **参数与单位**：`ptr` 为动态分配返回的指针，或 `NULL`
- **调用前提**：`ptr` 未被释放过，且不是 `NULL` 以外的非堆指针
- **返回值**：无
- **影响**：释放块；`ptr` 的值变为不确定
- **提醒**：`free(NULL)` 是合法的空操作；重复释放、释放后继续用、释放栈地址都是 UB；释放后建议置 `NULL`
- **三例**：默认 释放 `malloc` 块；自定义 释放 `calloc` 块；边界 `free(NULL)` 无动作
- **实测**：PASS（2 项，含 `free(NULL)`）

#### 52. `qsort` — §7.22.5.2
- **头文件 / 原型 / 条款**：`<stdlib.h>`；`void qsort(void *base, size_t nmemb, size_t size, int (*compar)(const void *, const void *));`；§7.22.5.2
- **参数与单位**：`nmemb` 元素个数、`size` 每元素字节；比较器返回 `<0/0/>0`
- **调用前提**：元素可按比较器比较；比较器给出全序且不得改数组
- **返回值**：无
- **影响**：原地重排 `base` 的 `nmemb` 个元素；**不保证稳定**
- **提醒**：比较器不要写 `return *a - *b`（会溢出）；不要依赖相等元素的先后
- **三例**：默认 `{5,2,9,1,5,6,0,3}` → 升序 `0..9`；自定义 重复 `5` 的位置不作承诺（按标准，本机仅记录命中偏移）；边界 `nmemb=0` → 不重排
- **实测**：PASS（3 项）

#### 53. `bsearch` — §7.22.5.1
- **头文件 / 原型 / 条款**：`<stdlib.h>`；`void *bsearch(const void *key, const void *base, size_t nmemb, size_t size, int (*compar)(const void *, const void *));`；§7.22.5.1

## 5. 参数单位口径（续）

| 函数 | 数值参数 | 单位 |
| --- | --- | --- |
| `printf`/`fprintf`/`snprintf` | 返回值 | 字符数（不含 NUL） |
| `scanf`/`fscanf` | 返回值 | 赋值项数（`0` 匹配失败、`EOF` 输入失败） |
| `fgets` | `n` | 缓冲区容量，含终止符；最多读 `n-1` 字节 |
| `fread`/`fwrite` | 返回值 | **元素个数**（`size*nmemb` 字节） |
| `malloc`/`calloc`/`realloc` | `size`/`nmemb` | 字节 / 元素个数 × 每元素字节 |
| `qsort`/`bsearch` | `nmemb`、`size` | 元素个数、每元素字节 |
| `fseek`/`ftell` | `offset`/返回值 | 字节（`long`），文本流受实现限制 |
| `difftime` | 返回值 | 秒（`double`） |
| `clock` | 返回值 | tick，`CLOCKS_PER_SEC` tick/秒 |
| `time` | 返回值 | `time_t`，编码未指定（通常秒） |

## 6. 未定义行为：只给触发条件与调用前提示

1. `printf`/`fprintf`/`snprintf` 格式与实参类型不匹配（如 `%d` 传 `long`）→ 提示：用 `%ld`，开 `-Wformat`。
2. `printf("%s", NULL)`、`scanf("%s", buf)` 不配宽度 → 提示：判空并限宽 `%9s`。
3. `scanf` 指针类型错（`%c` 传 `int *`、`%d` 传 `short *`）→ 提示：按转换说明选类型；本次写测时就踩过一次，值得做页面反例。
4. `%d` 读入超 `int` 范围的数字 → 提示：改用 `%ld`/`strtol`。
5. `atoi` 结果超出 `int` → 提示：用 `strtol` 判 `ERANGE`。
6. `strtol`/`strtod` 的 `base` 不在 `0`/`2..36`、`endptr` 非法 → 提示：固定用 10 或 0。
7. `realloc` 成功后继续用旧指针、`realloc(p,0)` 后使用 `p` → 提示：只保留新指针；`size 0` 属实现定义。
8. 双重 `free`、`free` 栈/中间指针、释放后读写 → 提示：释放后置 `NULL`，配合工具检测。
9. `qsort` 比较器不满足全序或修改元素；`bsearch` 在未排序数组上查找 → 提示：先排序，比较器只用只读访问。
10. `fclose(NULL)`、关闭后继续用流、`fopen` 返回 `NULL` 后读写 → 提示：先判 `NULL`，关闭后置 `NULL`。
11. 文本流上按任意字节 `fseek` 或用 `ftell` 差值跨平台 → 提示：二进制模式定位。
12. `fread`/`fwrite` 的 `size * nmemb` 超出缓冲区 → 提示：用 `sizeof` 计算。
13. `sqrt` 负数、`pow` 负底非整数指数、`sin`/`cos` 传 `±inf` → 提示：先校验定义域。
14. `time(NULL)` 之外传非法指针、`clock` 结果跨回绕直接相减 → 提示：用 `difftime`，`clock` 差值注意回绕。

## 7. 与 Codex 对接的注意点

- `scanf` 页面要能演示“`0` 与 `EOF` 是两件事”，输入区需要能编辑成失败样例（如 `abc`）。
- `snprintf` 页面应显示“返回 5、缓冲区 `"hel"`”这种“返回值与内容不一致”的画面，这是最容易被讲错的一点。
- `fread`/`fwrite` 的展示单位写成“元素”，并同时标出字节数（`size * nmemb`）。
- `realloc` 必须演示失败分支：返回 `NULL`、旧块仍可读；这是安全编码的核心。
- `qsort` 不要展示“相等元素的顺序”，页面上重复元素的位置要标注“未指定”。
- `clock` 的秒数换算要绑定 `CLOCKS_PER_SEC`，页面注明“本机 1000，POSIX 常见 1000000”。
- 数学函数页把 NaN、`-0.0`、`HUGE_VAL` 作为正常结果展示，不要显示成“错误中断”。
