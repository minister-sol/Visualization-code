## 一、阻断性缺口（按影响排序）

1. **位域静默错误**：`make_struct` 忽略 `Decl.bitsize`（backend/engine.py:806-817），sizeof 按完整类型计（:273）→ 寄存器映射、协议头、`:1` 标志值错且不报错。
2. **规模上限**：3000 步（:881）、3 万操作（:210）、数组≤1000（:726、:1276）、分配≤200（:1277）、递归 80（:1538）→ n≥100 循环、DP、全图遍历直接失败；web/app.js:34 的 truncated 分支服务端从不返回。
3. **union / goto**：union 未支持（:1918），无 goto 处理 → 变体记录与 cleanup 路径不可运行。
4. **裸字节分配**：只认 sizeof 推导出的元素类型（:1274-1276）→ `malloc(n)`、`malloc(100)` 拒绝。
5. **库与格式窄**：无 `%p`（integer_format.py）、strtok/sprintf/`%[...]`/argc·argv。
6. **诊断与文档**：解析错误无结构化行号（server.py:21）；README:63“535项”与 docs/COVERAGE.md:19“370项”、COVERAGE:389 与 engine.py:1496 不一致。
