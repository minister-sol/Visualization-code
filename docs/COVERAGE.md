### 浏览器回归的运行依赖与当前证据

`tests/browser_*.mjs` 当前共有18个脚本。脚本只使用 Node 内置 `fetch` 和 `WebSocket` 连接 Chrome DevTools Protocol，不依赖 Playwright、Puppeteer、npm 包或项目内的 Node 依赖。运行前需要：

1. Python 3.12（仓库已内置 pycparser），启动 `python server.py`（默认 `http://127.0.0.1:8000`，可用 `VISUALIZER_URL` 覆盖）。
2. Chromium、Chrome 或 Edge 以远程调试端口启动，并提供包含 `type: "page"` 的 CDP 页面目标（默认 `http://127.0.0.1:9223`，可用 `CDP_URL` 覆盖）。
3. Node 具备内置 `fetch`/`WebSocket`；本次复核使用 Node 24.20.0。无需 `npm install`。

本次复核环境中 Python 3.12.10、pycparser 3.12、Node 24.20.0、GCC 16.2.0 均可用；服务接口 smoke check 通过。由于没有运行在9223端口的 CDP 页面，18个浏览器脚本均未执行，不能把 artifacts 中的截图或历史记录当作本次浏览器回归证据。浏览器脚本覆盖条件/短路/断言、断点、历史定位、请求竞态、值变化追踪、对象过滤、对象图重连、字符串/格式/字节/输入/退出，以及若干数据结构页面；仍缺少统一批量 runner、无头浏览器启动步骤、移动端/可访问性/跨浏览器矩阵、性能/并发和网络中断验证。

对象图来自实际引用边。大量空指针字段按运行时指针槽信息折叠，普通数值0不会折叠。新折叠视图已通过布局测试和 Trie 浏览器展开/折叠检查。

## 尚需推进

- 更广泛的新源码与中间状态对照，以及复杂树图的浏览器验收。
- 存储期、临时对象、类型兼容、完整整数语义和不支持特性的可靠诊断。
- 常见语言写法与库函数仍有缺口，详见 README。当前不能把有限语料通过等同于绝大多数任意代码都可运行。
- 可视布局、密集连线和较大输入的体验，以及超出资源限制时的可解释反馈。
- 多语言适配尚未实现。

完成标准仍是输入新源码后生成可信、可回放、直观的数据结构状态；示例或绿色测试本身不能替代该标准。

新增 tests/test_generated_programs.py：12组随机输入及改名源码逐步核对数组访问值/身份，并检查带环对象在每帧中的引用目标存在。

浏览器批量验收已覆盖二叉搜索树、双向链表、Trie、线段树、循环队列、二叉堆、链式哈希、并查集、矩阵BFS、节点池DFS、动态顺序表和字符串键表。源码直接输入，12例输出、视图存在性和回放不变性均通过；报告位于 artifacts/acceptance-report.json。

### 结构体成员名与通用显示

普通结构体含 `value` 成员时保留全部字段，不再误按旧变量包装格式解包。前端回归覆盖嵌套数组、矩阵、引用成员，以及旧格式的变量变化和数组别名比较。浏览器实测包含 `value`、数组与矩阵的 C 结构体：输出 `7 9`，数组和矩阵均可显示，前后步进正常。

### 动态结构体数组扩缩容

支持带类型大小的结构体数组 realloc，包括嵌套数组成员和指针成员；复制原元素后释放旧存储，旧成员引用随之失效，独立指针目标保持有效。回归覆盖扩容、缩容、新成员未初始化及旧内嵌数组引用失效。新增节点池程序与 GCC 输出对照通过。当前采用始终移动的分配模型，不支持零长度 realloc。

### 常量表达式指定下标

数组指定初始化可使用枚举常量、整数算术及位运算表达式，例如 `[OPEN]`、`[CAPACITY-1]`、`[1<<BIT]`；支持嵌套在结构体成员初始化中，以及外层数组长度推导。回归检查实际数组快照，并拒绝变量、递增表达式、负数与越界下标。枚举索引表程序加入 GCC 输出对照。多层指定路径仍有限制。

### 整数常量表达式求值

常量逻辑运算遵循短路规则，三元表达式只计算所选分支并按公共整数类型转换；一元运算保留整数提升后的有符号性。支持整数显式转换，供枚举、case 标签和指定下标等调用方使用。回归包含跳过除零分支、无符号按位取反、三元类型转换与窄整数转换；常量配置数组程序与 GCC 输出一致。这不代表已覆盖完整 C 常量表达式语法。

### 与变量名无关的下标标记

数组单元格下方的定位标记来自本步读写轨迹的 `index_expression`，不再限定 i/j/left/right 等名称。复合表达式、任意变量名以及同一存储的偏移别名均按物理数组身份匹配，避免给无关数组或未参与访问的同值变量添加标记。Node 回归覆盖重命名、复合下标、去重和别名偏移；浏览器验证 cursor 游标链表遍历、标记和前后步进。整数数组仍按原数值显示，未将其自动解释为指针关系。

### 大数组分段查看

一维数组和逐行数组视图按每段 60 项显示，可通过上一段/下一段查看全部元素。本步存在访问时自动定位其所在段，优先写入；按存储身份及偏移处理别名。步进后恢复自动定位，手动换段不会改变执行位置。动画寻找单元格时扣除当前段起点。Node 回归检查分段边界、访问定位、别名与手动页；浏览器实测 100 元素数组第 95 项写入、游标标记、双向换段与回放。二维网格已支持行、列区段切换与访问自动定位。

### 二维网格区域定位

网格以每区段最多 30 行、30 列显示，支持分别选择行区段和列区段；按本步实际读写定位区域，优先写入，并通过各行数组存储身份及偏移匹配别名。步进后恢复自动定位。Node 回归覆盖超出首区段的访问、名称匹配和区段边界。浏览器使用 31×31（961 元素，符合执行器总元素不超过1000的限制）矩阵验证 [30][30] 写入、双轴自动定位、手动行切换与回放；一维大数组浏览器回归同时通过。

### 引用图的失效状态

对象字段显示悬空引用和数组偏移；失效引用以红色虚线及“悬空”文字标识，仍保留目标便于理解释放前后关系。根指针说明同步显示悬空状态。Node 回归验证连线状态与偏移文本；浏览器运行两个动态节点的引用和释放程序，核对释放后的红色虚线、悬空文字、输出与回放。

### C 复合字面量

支持结构体、整数和数组复合字面量，例如 `(struct P){.x=3,.y=7}`、`(int[]){2,4,6}`、`&(int){7}`。用于结构体赋值、按值传参、取地址和数组访问；匿名存储随所在作用域结束而失效，sizeof 类型检查不执行初始化。回归覆盖实际运算输出与悬空访问诊断，复合记录更新程序加入 GCC 对照。另已支持指针类型复合字面量、取地址与指针槽修改；函数指针等类型仍有限制。

指针复合字面量回归覆盖 `(int *){&x}`、`&(int *){p}`、双重间接写入和置空，以及非法整数地址拒绝；只读回归覆盖 const 数组、结构体和指针槽。同一作用域重复求值的标量字面量地址保持一致。新增指针槽程序与 GCC 输出对照通过。

### 受限函数式宏

支持单行固定参数的函数式宏，包括无参数宏、嵌套调用、参数中的括号和字符串保护。替换按 token 进行，不改变同名字符串或未调用的函数式宏名；参数会先展开。保留最大32层展开和50KB长度限制，递归、重复参数、参数数量不符及变参宏会报错。不带续行符的跨行调用、字符串化、拼接以及部分别名重新扫描情况仍未覆盖，不能视为完整 C 预处理器。新增以 PARENT/LESS 宏检查二叉堆的程序，输出与 GCC 一致。

### 条件编译与定义保护

支持 #ifdef/#ifndef/#else/#endif 嵌套，以及 #if 0、#if 1、defined(NAME)、!defined(NAME)。未启用分支不展开宏、不修改宏表、不处理 include 或其中的 C 代码；保留换行用于源码定位。最多64层，重复 else、孤立 endif 和缺失 endif 报错。回归覆盖定义保护、禁用分支、嵌套宏状态、源码行号及结构不匹配；带节点定义保护的程序加入 GCC 对照。已支持 #elif 和受限整数 #if 条件，不能替代完整 C 预处理器。

条件编译补充：支持 #elif 链，首个匹配后跳过后续条件求值；支持十进制/八进制/十六进制单整数和展开为单整数的宏开关，未知单标识符按0处理。回归覆盖嵌套未启用分支、后续不求值、defined 分支、非法 elif 位置。按配置选择不同结构体定义的程序已与 GCC 输出对照。已进一步支持整数复合条件，见下节。

### 预处理整数复合条件

独立表达式求值器支持 #if/#elif 中的整数算术、比较、逻辑、位运算、三元条件、ASCII 字符以及 defined。按64位 intmax/uintmax 求值，未知标识符为0，逻辑与三元分支遵循短路，不运行函数。限制表达式递归，拒绝不支持节点、除零、越界移位和有符号溢出。回归包含预处理宽度与普通 int 的差异、无符号运算、defined 组合、短路除零及负数余数。新增按表达式选择树数组容量的程序与 GCC 对照。尚不支持完整标准预处理器，如字符串化及 token 拼接。

### 反斜杠续行与多行宏

支持反斜杠+LF/CRLF 续行，包括多行对象宏、函数式宏和带续行符的调用。续行先于注释删除，避免 // 续行后的代码被错误执行；合并后补齐物理换行，保留后续行号。多行 do-while 交换宏验证实际结果和调用行写入轨迹，另覆盖 Windows 换行与注释续行。新增数组元素交换程序与 GCC 输出一致。不带续行符的普通跨行函数式宏调用仍未覆盖。

### 宏展开与源码对应

执行接口返回 preprocessed_source，界面提供可折叠的宏展开源码及原始物理行号，帮助将宏调用与执行表达式对应。运行时错误响应保留该源码；修改、切换代码或重新运行时清除旧结果。HTTP 回归检查展开内容、行号与错误响应，浏览器核对 DOUBLE(7) 展开、结果14、回放及编辑后清除。解析/预处理失败尚不一定能返回完整展开源码。

### 结构体成员地址可视化

指向已登记结构体标量/指针成员的引用带有所属对象 target 和 member，图中连线与字段文本标出目标成员；根指针说明也显示成员名。成员间重新指向会产生状态差异，释放/作用域结束后仍保留定位并显示悬空。Python 回归覆盖间接写入、成员切换及释放；前端回归覆盖目标成员文本、连线元数据和差异检测。浏览器实测 selected 从 value 切换到 other、输出12 9、连线与回放。

### limits.h 整数边界

内置 limits.h 支持 CHAR_BIT、SCHAR/CHAR/SHRT/INT/LONG/LLONG 的最小/最大值，以及 UCHAR/USHRT/UINT/ULONG/ULLONG 最大值。值遵循执行器的固定类型模型：char8、short16、int32、long与long long64，普通char为有符号；不代表宿主平台 ABI，尤其 Windows 原生 long 常为32位。测试覆盖边界值、64位值和预处理条件。新增使用 INT_MAX 哨兵的最短路松弛程序与 GCC 输出对照通过。

### 函数式宏别名与深度限制

支持对象宏经多层单标识符别名指向函数式宏，并消费调用处参数；未调用时保留最终函数式宏名称。循环别名与递归展开报错。参数括号计数与展开递归深度分离，避免嵌套调用重置深度限制；回归验证40层调用被限制。新增经 UPDATE→STORE→SET 别名链写入数组的程序与 GCC 输出对照。复杂替换边界重新扫描仍不等同完整标准预处理器。

### 对象图浏览

对象图默认适配完整拓扑，支持放大/缩小、原始大小、显示全图与按对象ID定位；定位对象有边框强调，原始/手动缩放下可滚动查看，步进保留滚动位置，编辑或切换源码恢复全图。浏览器使用新输入的12节点链代码生成222步轨迹，核对12节点、全图缩放、原始大小、末端节点定位与滚动、双向缩放及回放。前端布局和状态回归通过。

### 对象详情随步更新

点击对象、按Enter/空格或用下拉框选择对象，可在图下方查看完整字段（含折叠空引用）、存储状态和指向该对象的可见对象/变量引用。选择在步进时保留，详情按当前快照更新，编辑/切换源码清除选择。浏览器验证12节点链中 object-12 的写入后value11、回退后value0、再前进恢复11，以及定位、缩放和回放；前端布局与状态回归通过。

### 新输入 AVL 代码的结构验证

新增独立 AVL 插入源码，直接交给通用执行器，无算法ID或专用渲染器。六组插入顺序覆盖左旋、右旋、左右与右左双旋；从最终真实对象快照检查唯一根、无环、节点数量、二叉搜索顺序、每节点高度与平衡。六节点程序的输出与 GCC 对照通过。浏览器生成1207步，核对6节点、5条引用边、两次旋转调用、调用表达式、字段详情与回放。此证据覆盖该语料与这些输入，不能证明任意 AVL 实现或完整 C 都兼容。

### long 声明与整数格式

修复校验器拒绝 long 声明的缺口，支持 long/long int 及 signed/unsigned 形式和 signed long long，L/UL 字面量按模型64位处理。printf 增加 %ld/%li/%lu；scanf 增加长整数格式和 %i/%hi/%hhi/%li/%lli 自动进制读取，目标位宽/符号性仍校验。回归覆盖超JS精度长整数、结构体成员、字面量sizeof、十六进制/八进制和错误目标类型。新增长整数权重输入程序与 GCC 对照；该语料使用平台共有值域，不能证明模型long64与Windows原生long32 ABI相同。

### 十六进制与八进制输入输出

printf 支持 x/X/o 及 l/ll 长度，按对应无符号位宽格式化；scanf 支持 x/X/o 及 hh/h/l/ll 长度，支持十六进制可选0x前缀，并校验目标位宽和无符号类型。定向回归覆盖大小写、八进制、位掩码更新、窄整数、负值转无符号及错误目标类型。输入位图更新程序与 GCC 对照通过。格式标志、一般字段宽度与精度等仍未完整支持。

### 请求与源码版本一致性

编辑源码、输入或切换示例会取消当前请求并使其失效；旧响应、旧错误和旧 finally 回调不能覆盖新轨迹、展开源码或新请求的忙碌状态。浏览器用可控延迟响应验证旧请求先返回、新请求随后返回、输入编辑后旧结果返回，并恢复真实fetch。可重复测试为 tests/browser_request_races.mjs，需要运行服务及Chromium CDP，环境变量 VISUALIZER_URL/CDP_URL 指定地址。AVL端到端浏览器回归同步通过。

### 整数位视图
