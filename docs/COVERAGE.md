# C 语言知识覆盖与验收

本项目以完整 C 知识体系作为路线图，初版并非完整 C 标准实现。界面的知识点目录表示学习范围，不代表每项已经支持运行或动画。具体支持状态以追踪器实现和测试为准。

## 分层目标

| 层级 | 内容 | 验收方式 |
|---|---|---|
| 基础执行 | 变量、表达式、赋值、分支、循环、函数 | 将每步变量与人工推演的结果比较 |
| 排序教学 | 冒泡、选择、插入排序 | 重复值、负值、已排序数组均得到正确结果，回放保持一致 |
| 数组与引用 | 数组下标、指针、共享引用 | 显示引用对象与更新；不把模拟地址描述成真实地址 |
| 复合结构 | 结构体、链表、栈、队列、树 | 节点与连线随真实状态更新 |
| 语言进阶 | 预处理、类型转换、存储期、位运算、枚举、联合体 | 各特性分别列出支持限制和测试用例 |
| 系统能力 | 文件、动态分配、多文件、外部库、并发 | 后续版本；不能用示例动画替代实际执行支持 |

## C 知识体系清单

1. 编译流程：预处理、宏、头文件、条件编译、编译、链接、多文件工程。
2. 类型：整数、浮点、字符、布尔、枚举、void、typedef、限定符、类型转换与提升。
3. 表达式：算术、比较、逻辑、位运算、赋值、自增自减、条件和逗号运算符、求值顺序。
4. 控制流：if、switch、for、while、do while、break、continue、return、goto。
5. 函数：参数、返回值、递归、声明、可变参数、函数指针。
6. 数组与字符串：一维、多维、字符数组、字符串终止符、标准字符串函数。
7. 指针：取地址、解引用、算术、空指针、多级指针、数组退化和指针生命周期。
8. 复合类型：结构体、嵌套结构体、联合体、位域、对齐与填充。
9. 存储与内存：作用域、链接、存储期、static、extern、动态分配和释放。
10. 标准库：格式化输入输出、数学、字符串、内存、文件、错误处理与时间。
11. 数据结构：顺序表、链表、栈、队列、哈希表、树、图。
12. 算法：冒泡、选择、插入、归并、快速排序，线性与二分查找，遍历。
13. 正确性：数组越界、未初始化读取、悬空指针、溢出、未定义和实现定义行为。

## 发布验收

- 自定义源码必须影响执行结果，不能仅播放预制动画。
- 事件具有源码行号、变量快照、调用栈、输出；步骤可前进、回退、跳转。
- 编译或解析错误定位清楚；不支持特性明确报错，不能悄悄跳过。
- 死循环和过长运行触发步骤限制；浏览器仍能继续编辑和重试。
- 排序动画区分比较、交换、已处理位置；显示数组下标和值。
- 不把教育解释器声称为原生 C 编译器，不承诺覆盖未定义行为。
- 未经隔离的原生用户代码不得通过公共网络执行。

## 后续里程碑

初版基础追踪 → 完善指针与复合数据结构 → 真实编译器/调试器适配 → 多文件与标准库 → C++、Python、Java 适配。新增能力必须同时更新本表与回归测试。

## 当前已验证能力（输入与前缀和版本）

- int/long long 的 32/64 位范围检查，void；一维定长和变长整数数组。
- for/while/do while、if、break、continue、函数递归、短路及位运算。
- printf 的 %d/%i/%lld/%%、puts；scanf 的空白分隔 %d/%lld 与取地址目标。
- 每步源码行、变量、数组、调用栈、输出，以及输入读取与表达式事件。
- 七个内置示例与 GCC 标准输出一致；25 项单元/HTTP 测试通过。

尚未覆盖：浮点、char 变量、通用指针、动态内存、结构体、switch、多维数组、完整预处理、多文件及完整标准库。scanf 只支持上述整数格式，不代表通用指针已实现。所有输入运行前提供；不是交互式终端。整数溢出拒绝，不模拟平台溢出结果。
